# Sejarah Singkat: Sultan Muhammad Al-Fatih

Website statis berbahasa Indonesia yang menyajikan biografi singkat Sultan Mehmed II (Muhammad Al-Fatih), penaklukan Konstantinopel, fakta menarik, dan informasi profil.

## Fitur

- Navigasi ke bagian biografi, penaklukan Konstantinopel, dan fakta menarik.
- Tata letak responsif untuk layar desktop dan perangkat seluler.
- Profil Mehmed II dengan informasi masa kekuasaan, kelahiran, kematian, dan pemakaman.

## Teknologi

- HTML5
- CSS3
- Google Fonts (Quicksand)

## Menjalankan proyek

Tidak diperlukan instalasi atau proses build. Buka `index.html` di browser, atau jalankan melalui ekstensi seperti Live Server di Visual Studio Code.
